# ⏱️ Time & Space Complexity

Understanding complexity is an important part of my DSA journey.

### Common Time Complexities

| Complexity | Name |
|---|---|
| `O(1)` | Constant |
| `O(log n)` | Logarithmic |
| `O(n)` | Linear |
| `O(n log n)` | Linearithmic |
| `O(n²)` | Quadratic |
| `O(2ⁿ)` | Exponential |
| `O(n!)` | Factorial |

### General Growth Order

```text
O(1)
   ↓
O(log n)
   ↓
O(n)
   ↓
O(n log n)
   ↓
O(n²)
   ↓
O(2ⁿ)
   ↓
O(n!)
